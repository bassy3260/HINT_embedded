# FreeRTOS 프로젝트

| 프로젝트 | 내용 |

| [RTOS_ISR_PROSUMER](RTOS_ISR_PROSUMER/README.md) | 임계 구역으로 공유 버퍼 보호 |
| [RTOS_ISR_QUEUE_DEMO](RTOS_ISR_QUEUE_DEMO/README.md) | 버튼 인터럽트로 큐 비우기·채우기 |
